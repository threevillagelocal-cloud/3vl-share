# 3vl-share
Social share images for threevillagelocal.com listings. Generated by 3vl-assets/site/share-img/gen.py - do not edit by hand.

t/ = small WebP copies of photos the site shows (event photos, logos, story images), made by t/gen.py every 30 minutes. File name = FNV-1a hash of the original URL + width. The site falls back to the original when a copy is missing.
